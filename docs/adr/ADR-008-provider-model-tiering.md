# ADR-008: Provider와 모델 티어 전략

- **상태:** 제안됨 (Interactions API는 실측 대기)
- **일자:** 2026-09-03
- **관련:** ADR-004, ADR-007
- **근거 문서:** [05](../05-cost-latency-reality.md), [06 §5](../06-data-model.md), [08 D3](../08-decisions-under-uncertainty.md)

## 맥락

이 검토는 외부 LLM Provider를 쓰는 서비스를 전제로 한다. 유사 서비스 중에는 **자체 SLM**으로 원가를 풀어 흑자를 냈다는 공개 사례가 있다.

```
자체 모델 → 토큰당 단가를 직접 낮출 수 있음
외부 API  → 단가 고정. 낮출 수 있는 건 토큰 "수"와 캐시 적중률뿐
```

**같은 품질을 더 적은 토큰으로 내야 하는 구조적 제약**이 있다. 다만 비용은 목적함수가 아니라 제약조건이다 — 엔터테인먼트에서 품질이 나쁘면 유저는 그냥 다른 걸 본다.

## 결정 동인

1. 응답 품질 (제약이 아니라 목적)
2. TTFT
3. 턴당 원가 상한
4. 한국어 처리 효율

## 결정

> **① Provider는 Gemini를 기본으로 한다.**
> **② 모델은 티어별로 다르게 쓴다 — 무료 티어는 컨텍스트를 줄이지 말고 모델을 내린다.**
> **③ 쓰기 경로는 전부 Batch/Flex(50%↓)로 내린다.**
> **④ Interactions API는 실측 전까지 채택하지 않는다.**

## 근거

### ① 왜 Gemini인가

- **한국어 토큰 효율이 가장 좋다.** 한국어는 영어 대비 2~3배 토큰을 쓰는데, 토큰 효율 순위가 Gemini > GPT > Claude로 보고된다. 명목 단가가 같아도 **실질 단가가 다르다** ⚠️ 2차 출처 — 자체 측정 필요(같은 한국어 롤플레이 텍스트를 각 토크나이저에 넣어 세면 30분)
- Flash 계열의 가격·품질 균형이 이 용도에 맞다
- Batch·Flex·context caching이 모두 제공된다

### ② 티어링 — 컨텍스트를 조이는 것보다 모델을 내리는 게 낫다 ⭐

| 구성 | 원가/월 (헤비 유저) |
|---|---|
| Flash + 컨텍스트 1,000토큰 | **$17.44** |
| **Flash-Lite + 컨텍스트 4,000토큰** | **$2.90** |

**컨텍스트를 4배 조이는 것보다 모델을 한 단계 내리는 게 6배 싸다.**

이유는 **출력 비용 바닥**이다. Gemini Flash는 출력 단가가 입력의 5배이고 롤플레이 응답은 길다(한국어 ~400토큰). 컨텍스트를 0으로 만들어도 월 $15가 남는다.

```
4K 컨텍스트, 캐시 없음 : 입력 $30.00 + 출력 $15.00 = $45.00
4K 컨텍스트, 캐시 75%  : 입력  $9.75 + 출력 $15.00 = $24.75  (출력이 61%)
컨텍스트 완전 제거      : 입력     $0 + 출력 $15.00 = $15.00
```

> **메모리 아키텍처가 건드릴 수 있는 건 총비용의 약 40%다. 모델 등급 한 단계가 88%다.**
> **→ 메모리 시스템의 경제적 가치는 토큰 절감이 아니라, "더 싼 모델로 내려가고도 품질을 유지할 수 있게 하는 것"이다.**

그리고 이 방향을 지지하는 반직관적 사실이 있다 — **작은 모델이 노이즈에 더 강하고 큰 모델이 더 쉽게 산만해진다.** 정밀한 메모리와 작은 모델은 같은 방향으로 작동한다.

**롱테일 캐릭터 정책:** 캐릭터 인기는 멱법칙을 따르므로 비인기 캐릭터는 [유저 간 캐시 공유](ADR-007-context-packing-cache.md) 이득이 없어 **구조적으로 비싸다.** 그런데 UGC 플랫폼은 캐릭터가 많아야 성장한다.
→ **트래픽 하위 캐릭터는 더 싼 모델 티어로 자동 강등.** 사용자가 적어 품질 리스크 노출도 작다.

> ⚠️ **실측 후 근거 약화** ([11 §4](../11-experiment-results.md))
> 유저 간 접두사 공유 이득이 세션 50턴 기준 **0.6%**에 불과했다. 세션이 짧을 때만(5턴 → 5.2%) 의미가 있다.
> **인기/비인기 캐릭터 간 원가 차이가 생각보다 작다.** 이 정책의 근거였던 "롱테일이 구조적으로 비싸다"가 약해졌다.
> → **재검토 대상.** 강등을 정당화하려면 다른 근거(예: 신규 캐릭터의 낮은 리텐션)가 필요하다.

### ③ 쓰기 경로를 할인 티어로

| 티어 | 특성 | 용도 |
|---|---|---|
| **Batch** | 비동기, 24h SLA, **50%↓** | 세션 종료 후 사실·사건·해석 추출, 장기 요약 |
| **Flex** | **동기**, 1~15분, **50%↓** | 세션 중 요약 갱신, 부채 등록 |
| Standard | 즉시 | 응답 생성만 |
| Priority | +80%, 타이트한 SLA | 채택 안 함 (원가 압박) |

**Flex의 발견이 중요하다.** Batch와 동일한 50% 할인인데 동기 인터페이스다. 24시간은 너무 길고 즉시성은 필요 없는 작업이 정확히 여기 들어간다. → 쓰기 경로를 2단으로 쪼갤 수 있다.

### ④ 왜 Interactions API를 지금 채택하지 않는가

원래 질문이 언급한 축이지만, **세 가지 이유로 보류한다.**

1. **과금 입력 토큰이 실제로 줄어드는지 문서에 명시가 없다.** `previous_interaction_id`는 **전송 페이로드**를 줄인다. 서버가 히스토리를 전부 재구성한다면 `O(N²)` 문제는 그대로다
2. **explicit caching을 지원하지 않는다.** [ADR-007](ADR-007-context-packing-cache.md)의 배치 전략과 배타적일 수 있다
3. **beta이고, 공식 문서가 프로덕션에는 `generateContent`를 권한다**

> **→ 이건 "안 쓴다"가 아니라 "실측 전에는 못 정한다"이다.**
> 키 확보 시 최우선 실험: 같은 대화를 stateless와 `previous_interaction_id` 양쪽으로 진행하며 **턴별 과금 입력 토큰과 `usage.total_cached_tokens`를 비교**한다. 10분이면 끝난다.
> **과금 토큰이 턴 수에 비례하지 않는다는 결과가 나오면 이 ADR을 뒤집고 별도 ADR로 승격한다.**

## 결과

**좋아지는 것**
- 무료 티어 원가가 $24.75 → $2.90 수준으로 내려간다
- 쓰기 경로 비용이 주입 비용의 3.6%로 억제된다

**감수하는 것**
- 티어별로 다른 모델을 쓰므로 **품질이 유저마다 다르다.** 무료 유저의 체감 품질이 상한선이 아니다
- 모델 강등이 어디까지 견디는지 미검증 — **`모델 × 메모리 구조` 교차 실험이 필요하다**
- 외부 API 의존이라 Provider 정책 변경 리스크가 있다

**주의:** Gemini 3.x Flash 단가는 2026-12-31까지 도입가이고 **2027-01-01부터 인상 예정**이다. 원가 모델을 그때 다시 계산해야 한다.

## 재검토 트리거

- **Interactions API 실측에서 과금 토큰이 줄면** → 즉시 재검토, 별도 ADR
- Flash-Lite 강등 시 품질 지표가 5%p 이상 하락하면 → 티어링 축소
- 2027-01-01 단가 인상 시 → 전체 원가 모델 재계산
- 자체 모델 도입이 검토 대상이 되는 시점: **월 LLM 비용이 GPU 상각 + 인력 비용을 넘을 때.** 그 전에는 외부 API가 옳다
