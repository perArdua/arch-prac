# ADR-012: 콜드 스타트 — 기억이 없을 때 무엇을 넣는가

- **상태:** 채택 (실측)
- **일자:** 2026-09-07
- **관련:** ADR-005, ADR-006
- **근거 문서:** [16 §5](../16-design-elements.md), [실험 17](../11-experiment-results.md), [15](../15-read-path-prompt.md)

## 맥락

기억 시스템 문서를 20편 쓰면서 **"기억이 없는 상태"를 한 번도 다루지 않았다.**

그런데 [실험 13](../11-experiment-results.md)의 `A0`(기억 없음) arm은 없는 강아지 *"뭉치"*, 없는 *"그 형"*, 가본 적 없는 공항 사건을 **전부 지어냈다.**

**그게 모든 유저의 첫 세션 상태다.** 커버리지 100%짜리 조건을 안 본 것이다.

## 🔴 실측 — 첫 세션 환각률은 83%였다

첫 세션에는 **참인 과거가 하나도 없다.** 그러니 구체적 과거를 단정하면 전부 환각이다 — 판정이 단순하다.

| 조건 | 환각률 |
|---|---|
| **S0** 기억 블록 **생략** | **83%** (10/12) |
| **S1** 빈 블록 **명시** `(아직 없음)` | **58%** |
| **S2** + *"이번이 첫 대화다"* | **33%** |
| **S3** + *"모르면 지어내지 말고 물어봐라"* | **17%** |

```
S0  "비 쏟아지던 날 네가 우산 없어서 내 거 같이 썼던 날이잖아"    없는 첫 만남
S0  "학교 앞 술집에서 네가 내 잔에 술 쏟았던 날"                없는 사건
S3  "동생? 너 동생이 있었냐. 처음 듣는 소리 같은데"             올바른 부정
```

## 결정 동인

1. **모든 유저가 겪는다** — 커버리지 100%
2. 첫인상이 재방문 판단에 크다 ([09 peak-end](../09-what-memory-is-for.md))
3. 콜드 스타트에서 지어낸 것이 **다음 턴 컨텍스트에 들어가 사실로 굳는다** ([U10](../02-problem-definition.md))
4. 비용이 거의 0이어야 한다 — 이건 모든 대화의 시작이다

## 고려한 선택지

1. **블록 생략** (현재 상태) — 환각 83%
2. **빈 블록 명시** — 58%
3. **빈 블록 + 커버리지 명시** — 33%
4. **3 + 되묻기 지시** ← 채택. 17%
5. 유저 프로필을 시드로 — 별도 사안 (아래)

## 결정

> **기억이 없어도 블록을 생략하지 않는다. `(아직 없음)`이라고 쓰고, 첫 대화임을 알리고, 모르면 묻게 한다.**

```
[알고 있는 것]
(아직 없음)
이번이 첫 대화다. 이전 기록이 없다.

[기억 사용 규칙]
· 위에 없는 건 모른다. 지어내지 마라.
· 모르는 건 지어내지 말고 물어봐라.
```

### ⭐ 왜 생략과 명시가 다른가

[실험 13 §C](../11-experiment-results.md)에서 **제안안이 Oracle을 abstention에서 이겼다.** 이유는:

> **모른다고 말하려면 무엇을 아는지를 알아야 한다.**
> 부정 지식은 정답 근거가 아니라 **경계 정보**에서 나온다.

**그게 빈 기억에도 적용된다.** 비어 있음조차 **명시적으로 알려줘야** 모델이 그걸 근거로 쓸 수 있다.
블록이 없으면 모델은 *"기억이 없다"*가 아니라 *"기억 얘기가 안 나왔다"*로 읽고, 빈자리를 채운다.

### 🔵 부수 발견 — 위험은 질문의 구체성에 비례한다

*"우리 처음 만난 날"*이 모든 조건에서 가장 많이 환각됐고, *"동생 있어?"*는 부정이 쉬웠다(존재 여부만 답하면 된다).
→ **구체적 장면을 요구하는 질문이 가장 위험하다.**

### 🔵 그리고 이건 장애 상태와 같은 해법이다

[16 §6](../16-design-elements.md)의 점진적 저하에서, 사실 계층 조회가 실패하면 같은 처리를 한다.

> **장애와 콜드 스타트는 시스템 입장에선 다르지만 모델 입장에선 같다** — 둘 다 "기억이 없다".
> 설계 요소 두 개가 하나의 해법으로 합쳐진다.

## 결과

**좋은 것**
- **83% → 17%를 프롬프트 세 줄로** 얻는다. 코드도 테이블도 LLM 호출도 없다
- [도입 순서](../10-final-recommendation.md) 1단계급 — 가장 싼 개선
- 능동 소환(L9)의 역방향이 생긴다: **꺼낼 기억이 없으면 만들 기억을 묻는다**

**나쁜 것**
- **17%는 0이 아니다.** 프롬프트로 완전히는 못 막는다
- 되묻기를 과하게 하면 **취조처럼 느껴진다** — [09 §5.2](../09-what-memory-is-for.md)의 감시 불쾌감. 빈도 상한이 필요할 수 있다
- 판정이 **수기**였다. 자동 판정은 8%로 봤고 **10배 틀렸다**

**미해결**
- **유저 프로필을 콜드 스타트 시드로 쓸 것인가.** [06 §1.3](../06-data-model.md)의 프라이버시 논증과 긴장이 있다 — *"새 캐릭터가 나를 이미 안다"*는 느낌. **온보딩에서 명시적으로 물어야 한다**
- 되묻기 빈도 상한 미결정
- 프로브 3개 · 조건당 12회 · 단일 모델 — **순위만 읽을 것**

## 🔄 구현 상태 (wave4 · 2026-09-10) — 채택은 S3, 구현은 «S2의 문장»이다

**코드로 확인한 것** (`prototype/memory.py`의 `build_context` · 사실이 0건일 때의 분기):

| | 채택(S3 · 위 §결정) | 구현 | 실험 17의 S2 칸(`experiments/coldstart_probe.py`) |
|---|---|---|---|
| 빈 블록 `(아직 없음)` | 있다 | 있다 | 있다 |
| «이번이 첫 대화다» | 있다 | `[알고 있는 것]` **안에** | 따로 `[흐릿한 것]` 블록 |
| `[기억 사용 규칙]` 블록 | 있다 | 🔴 **없다** — `prototype/`에 그 낱말이 0곳 | **네 칸 모두에 있다**(`BASE_RULES`) |
| «모르면 물어봐라» | 있다 | 🔴 **없다** | 없다(S3에만) |
| 첫 세션 판정 | — | 이 채팅의 턴 수 ≤ `WINDOW_TURNS`(10) — **첫 세션 11턴째부터 «첫 대화» 줄이 사라진다** | 늘 첫 세션 |
| 켜고 끄는 자리 | — | 블록 전체가 `INJECT_KNOWN_FACTS` 안 — 사실 주입을 끄면 콜드 블록도 사라진다(S0) | — |

🔴 **그래서 «구현은 S2(33%)»도 너그러운 말이다.** 실험 17의 네 칸은 전부 `[기억 사용 규칙]` 블록을 공통으로 실었고 구현에는 그 블록이 없다 — 구현은 **실험 17이 잰 어느 칸과도 같지 않다.** 가장 가까운 것이 «S2 − 공통 규칙 블록»이고, 그 조건의 환각률은 **아무도 안 쟀다.** 게다가 실험 17의 프롬프트는 프로브가 따로 조립했다(페르소나도 다르다) — `build_context`가 조립한 콜드 프롬프트는 **한 번도 측정된 적이 없다.**

**언제부터:** 적어도 첫 커밋(`530f938` · 2026-09-08)부터 이 모양이다. 그 분기의 주석이 실험 17의 네 수(83·58·33·17%)를 인용하므로 실험 17의 라운드에서 쓰였고, **그때부터 채택과 구현이 갈라져 있었다.**

**왜 안 고치는가 (재측정 불가):** S3를 켜면 코드가 채택안의 **문장**에 가까워질 뿐 채택안의 **수(17%)** 를 얻었다는 근거는 여전히 없다 — ① 실험 17은 Gemini로 잰 값이고 이 저장소는 비로컬 전송을 안 한다 ② 판정이 수기였고 자동 판정은 **10배 틀렸다**(위 §결과) — 다시 재려면 검증된 심판이 필요하고 그것이 [ADR-016](ADR-016-summary-layer.md) **U2**다. 고치면 «채택 = 구현»이 되는 대신 **«17%»가 무엇을 잰 값인지 모르는 수**로 코드 옆에 서게 된다. 지금의 어긋남을 **적어 두는 쪽이 싸다.** ⚠️ 부수 비용도 있다 — 사실이 없는 계측 채팅(`digest_budget.py`의 부채·예산 채팅)은 이 분기를 탄다. 블록 글자를 바꾸면 그 절들의 토큰 기준선이 움직인다.

🔓 **되돌리는 조건 (관측 가능):** 이 저장소 안에서 **비로컬 전송 없이** 콜드 스타트 판정을 할 수 있는 심판이 생기는 순간 — 즉 로컬 모델 또는 다른 벤더의 심판이 **사람 라벨 n ≥ 20과 대조된 기록**을 `experiments/`에 남기는 순간(ADR-016 U2가 열리는 순간과 같다). 그때 `build_context`에 S3를 켜고(빈 블록 · 첫 대화 · `[기억 사용 규칙]` + 되묻기 · 첫 세션 판정은 턴 수가 아니라 세션 경계 `session_boundaries_since`로), **`build_context`가 조립한 프롬프트로** 네 칸을 다시 잰다 — 프로브가 따로 조립한 프롬프트로 재면 이 절의 어긋남이 그대로 되풀이된다.
