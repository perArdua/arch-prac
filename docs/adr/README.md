# 결정 기록 (ADR) — 색인과 근거 감사

> 001~010은 **제안됨**이다(배포된 것이 없다). 011~014와 **016**은 프로토타입에 **구현·실측**되어 채택으로 표시한다.
> **015는 구현이 아니라 측정만으로 채택된 음성 결과다** — *"바꾸지 않는다"*가 결정이고, 그 결정의 근거가 측정이다.
> 🆕 **016은 «재는 것 하나»만 들고 채택됐다** — 서빙 정책의 델타는 실측했고, **요약 품질에 대해서는 아무 숫자도 내지 않는다.** 그 자리를 «후속»으로 비워 두고 **비운 이유를 적는 것**이 그 ADR의 §결과가 하는 일이다.
> 아래 표는 **각 결정이 무엇으로 뒷받침되는지**를 정직하게 분리한 것이다. 🔄 *(w12close · 2026-09-11) 행마다 끝에 **생성 조건**을 붙였다 — 012 · 013의 품질 수치는 Gemini · temperature 0.7, 015의 응답 수준 수치는 로컬 qwen3:8b · temperature 0이라 같은 «🟢 실측» 색이 같은 자를 뜻하지 않는다([docs/17](../17-gap-disposition.md) ❔6)*

> ### 🆕 011~013은 다른 경로로 나왔다
>
> 001~010은 **설계를 먼저 하고 실험으로 검증**했다.
> 011~013은 [16 설계 요소 점검](../16-design-elements.md)에서 **목록을 훑다가 빈칸으로 발견**된 것들이다.
> 실험은 내가 이미 생각한 것만 검증하므로, **이 셋은 실험으로는 나오지 않았을 것**이다.

## 실험이 뒤집은 ADR

| ADR | 원래 주장 | 실측 후 |
|---|---|---|
| **005** | 가중합 `w_rel·rel + w_imp·imp` | 🔴 **하드 게이트가 앞에 필요.** 가중합만으로는 사소한 기억을 못 거른다 |
| **006** | "하이브리드 검색 필수" | 🔴 **"dense 우선, BM25 조건부"로 강등.** naive RRF는 dense 단독보다 나쁘다 |
| **007** | 배치 순서가 핵심 | 🆕 **슬라이딩 윈도우 축출이 더 큰 레버** (47%↓ vs 29%↓) |
| **008** | 롱테일 캐릭터 모델 강등 | ⚠️ **근거 약화.** 유저 간 캐시 이득이 0.6%뿐 |
| **002** | L9 부채 스키마 | 🔴 **필드 3개 누락.** 백오프·시계 명시가 없었다 |
| **013** | P4 = *"**모든 세션 요약**에서 재작성"* (사슬 깊이 2) | 🔴 **현행 스키마에서 실행 불가능했다.** `digest`의 PK가 `(chat_id, kind)`라 세션 요약이 채팅당 1행이고, *"모든 세션 요약"*이라는 입력 집합의 크기가 **1**이었다 — 즉 스키마가 지원하는 유일한 재작성 방식이 **ADR-013이 기각한 P2**였다. [016](ADR-016-summary-layer.md)이 `digest_session`으로 실행 가능하게 만들었다. ⚠️ **결정은 안 뒤집혔다** — 뒤집힌 것은 *"채택했으니 돌고 있다"*는 암묵 전제다 |
