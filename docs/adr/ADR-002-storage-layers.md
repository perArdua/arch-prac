# ADR-002: 저장 계층 구조 — 무엇을 어떤 형태로 남기는가

- **상태:** 제안됨
- **일자:** 2026-09-03
- **관련:** ADR-001, ADR-003, ADR-005, ADR-010
- **근거 문서:** [06 §2](../06-data-model.md), [02 P4](../02-problem-definition.md), [09](../09-what-memory-is-for.md)

## 맥락

대화 기록을 어떤 형태로 남길지는 표현(원문/요약/사실/트리플/구조화)과 계층(단일/다층)의 두 축으로 갈린다. 그리고 이 결정이 이후 검색·주입·모순 처리의 가능성을 전부 규정한다.

**설계를 "세상에 무슨 정보가 있나"에서 시작하면 실패한다.** 무한히 나열하게 되고 각 필드가 왜 필요한지 답할 수 없다. 그래서 **실제 서비스의 실패 사례**와 **답해야 할 질의 유형**에서 역산했다.

## 결정 동인

1. 각 필드가 **막는 실패**가 명확할 것
2. 항상 참인 것과 조건부인 것의 분리
3. 주입 토큰 예산 (필드마다 정당화)
4. 모순 처리 가능성

## 고려한 선택지

1. **단일 표현** — 원문만 / 요약만 / 사실만
2. **최근·장기 2층** — 흔히 쓰는 계층형 메모리 구조(현행 기준선)
3. **역할별 다층** — 데이터 성격마다 별도 계층

## 결정

> **우리는 3번을 선택한다. 10개 계층으로 나누고, 분할 축은 "최근성"이 아니라 "항상 참인 상태 / 조건부 사건"이다.**

```
L0 원본     전부·영구, 주입 안 함
L1 정적     페르소나 + speech_rules(별도 필드) + 세계관
L2 관계상태  enum + note. 항상 주입 (결정적)
L3 씬상태    현재 참여자·장소. 항상 주입
L4 요약      session / lifetime 2층
L5 사실      bi-temporal. 조건부 주입
L6 사건      감정 무게 + surfaced_count. 조건부 주입
L7 고유명사   정확 문자열. 색인 전용
L8 캐릭터 자기기억  해석 / 자기상태 / 의견
L9 서사 부채  트리거 + 이행 상태. 결정적 주입
M  커버리지   구간별 해상도
```

## 근거 — 각 계층이 막는 실패

| 계층 | 없으면 생기는 실패 | 출처 |
|---|---|---|
| L1 `speech_rules` 분리 | 페르소나가 산문에 묻혀 50턴 뒤 희석 → 캐릭터 붕괴 | 유사 서비스 C 페르소나 붕괴 |
| **L2 결정적 주입** | 헤어졌는데 "자기야" — 상태가 top-k에서 밀림 | 유사 서비스 A stale fact |
| L3 참여자 명부 | 엄마·친구가 시도 때도 없이 난입 | 유사 서비스 A U6 |
| L5 bi-temporal | 갱신된 사실의 옛 버전 재생 | 지식 갱신 질의 |
| L6 감정 무게 | «빵 유언» — 사소한 걸 중요하게 회상 | 유사 서비스 A 후기 |
| L7 정확 문자열 | 이름 오류 — 임베딩은 고유명사의 지시체를 못 담음 | 유사 서비스 A U9 |
| **L8 캐릭터 자기기억** | 유저 기억만 쌓여 캐릭터가 "빈 그릇"이 됨 | 적응 역설 (역U자) |
| **L9 부채** | 약속을 안 지킴 — LLM은 컨텍스트가 있어도 복선을 회수 못 함 | CFPG |
| M 커버리지 | *"그런 적 없다"*와 *"기억이 흐릿하다"*를 구별 불가 | abstention |

**L5와 L6을 나누는 이유:** 사실은 **상태**(참→거짓)이고 사건은 **점**(일어났고 안 사라짐)이다. 같은 테이블이면 무효화 로직이 사건에도 적용되어 **과거가 지워진다.**

**L9가 L6과 다른 이유:** 사건은 안 꺼내도 무해하지만, **부채는 안 갚으면 관계가 손상된다.** 그래서 확률적 검색이 아니라 결정적 주입 대상이다.

## 결과

**좋아지는 것**
- 각 실패 유형에 대응하는 자리가 명확하다
- 상태(고정 토큰, 캐시 가능)와 사건(가변)의 분리로 캐시 전략이 성립한다(ADR-007)
- 모순 검사가 정규식 수준으로 싸진다 (L2가 enum이므로)

**감수하는 것**
- 테이블 10개. 단일 표현보다 복잡하다
- 추출기가 계층 판정까지 해야 한다 (ADR-004)

**새로 생기는 장애 지점**
- 계층 간 정합성 — L2 상태와 L5 사실이 충돌할 수 있다 (예: `stage=헤어짐`인데 `fact(연인관계)` 유효)
  → **L2를 단일 진실원(source of truth)으로 두고, 충돌 시 L2가 이긴다**

## 재검토 트리거

- L8 해석 주입이 L5/L6 사실 주입보다 반응성 지표를 못 올리면 → L8 축소, 계층 9개로
- L9 부채의 이행률이 낮은데 품질 차이가 없으면 → L6에 흡수
- 계층 간 정합성 사고가 월 N건 이상이면 → 계층 병합 재검토
