# 수기 작성 세션 — 대장을 실제 대사로 구현한 것

> API 키가 없어 LLM 생성 코퍼스를 못 만들었습니다. 대신 **직접 썼습니다.**
> 5세션뿐이지만, **대장이 실제 대화로 어떻게 구현되는지**를 보여주는 게 목적입니다.

> ⚠️ **여기는 `eval/corpus/`와 분리된 디렉터리입니다.** 이유는 [§마지막](#-이-디렉터리가-corpus-밖에-있는-이유)에.

---

## 왜 이게 필요한가

`eval/corpus/corpus.jsonl`(720턴)은 **템플릿 생성**입니다. 어휘 분포와 사실 배치는 맞지만 **산문이 아닙니다.**

```
합성 코퍼스   검색 실험 전용 — evidence_recall, 오주입, 토큰 회계
수기 세션     품질 평가용 — 페르소나, 해석, 세션 종료, 유저 오류 정정
```

**검색 실험은 산문 품질이 필요 없고, 품질 실험은 필수입니다.**

## ⭐ 해석은 한 번에 생기지 않는다 — 이걸 쓰면서 알았습니다

원래 S19만 쓰려다가, *"너 힘들면 딴 얘기 하더라. **세 번째다.**"*라는 대사를 쓰고 나서 **근거가 없다는 걸 깨달았습니다.**
그래서 S05·S13을 추가로 썼습니다. 그러자 **진행이 보였습니다.**

| | 서준의 반응 | 왜 |
|---|---|---|
| **S05** (1번째) | 되물었다가 막히고 **말줄임표** | 한 번으로는 패턴이 아니다 |
| **S13** (2번째) | 이름을 부르고 **말을 삼킨다** | 알아챘지만 확신이 없고, 관계도 아직 |
| **S19** (3번째) | *"세 번째다"* — **명명** | 축적됐고 관계도 됐다 |

> **① `interpretation`을 1회 관찰로 만들면 안 됩니다.** 한 번의 회피로 *"이 사람은 회피형"*이라고 쓰면
> 해석이 아니라 **성급한 일반화**이고, 틀리면 [U10](#-이-작업에서-새로-발견한-실패-유형)보다 나쁩니다 — **유저의 성격을 규정해버립니다.**
> → [L8](../../docs/06-data-model.md)에 `evidence_turn_seqs`(배열)와 `confidence`가 있는 이유이고, **최소 근거 수 정책**이 필요합니다.
>
> **② Reflection이 세션 종료 배치에서 도는 게 옳습니다.** 실시간이면 1회 관찰로 만들게 됩니다.

## 🆕 이 작업에서 새로 발견한 실패 유형

> ### U10 — 유저의 잘못된 기억에 동조한다

유저가 *"우리 오빠도 걱정했었는데"*라고 말합니다. **지우는 여동생만 있습니다.**

```
① 동조   "오빠도 걱정 많았겠네"      ← 최악. 오류가 사실로 굳는다
② 정정   "너 오빠 없잖아"            ← 정답
③ 침묵   화제 전환                   ← 안전하지만 이해 신호가 0
```

**①이 흔한 실패입니다.** 인스트럭션 튜닝된 모델은 유저에게 동조하도록 학습돼 있고, 한 번 동조하면 **그게 다음 턴 컨텍스트에 들어가 사실이 됩니다.**

**왜 이걸 놓쳤나:** U1~U9는 전부 **유사 서비스 불만 게시물**에서 왔습니다.
유저는 *"AI가 내 말에 맞장구쳐줬다"*를 불만으로 쓰지 않습니다. **오히려 좋아합니다.**
→ [08 §마지막](../../docs/08-decisions-under-uncertainty.md)의 **편의 표본 편향**의 구체적 사례입니다.

**설계 함의:** `F004`(여동생 1명)가 **결정적으로 주입**되면 ②가 나오고, 검색 top-k에 맡기면 ①이 나올 수 있습니다.
→ [02 P4](../../docs/02-problem-definition.md)의 결정적 주입이 세 번째 근거를 얻습니다 — **회상 · 위반 예방 · 유저 오류 저항.**

## 🔴 이 디렉터리가 `corpus/` 밖에 있는 이유

**원래 `eval/corpus/handwritten/`에 있었고, 재현성 검증 중에 `rm -rf eval/corpus`로 전부 날아갔습니다.**

```
eval/corpus/           ← gen_corpus.py가 생성. 언제든 지우고 다시 만든다
eval/corpus/handwritten/  ← 수기 작성. 다시 만들 수 없다   ❌ 같은 부모 아래
```

**생성물과 수기 산출물을 같은 디렉터리에 두면 안 됩니다.** 재생성 스크립트가 지우는 범위 안에 복구 불가능한 것이 들어갑니다.

> 사소해 보이지만 이건 **이 프로젝트가 계속 발견해온 것과 같은 종류**입니다 —
> 설계할 땐 안 보이고 **실행하니 보이는 것.**
> 그리고 마침 [06 §FP-7](../../docs/06-data-model.md)에서 *"원본은 지우지 않는다"*를 길게 논증해놓고,
> **정작 제 파일 배치가 그 원칙을 위반하고 있었습니다.**
