## 목적은 성능이 아니다

**설계가 놓친 것을 드러내는 것**이다. 그리고 실제로 드러났다 — **설계 결함 10개.**

| # | 무엇이 | 어디서 |
|---|---|---|
| 1 | 어미 정규화 없이는 `아팠던`≠`아파서`라 **정답이 탈락** | `demo.py` |
| 2 | **"결정적 주입"을 "앞쪽 배치"와 혼동** — 접두사 57% → 100% | `demo.py` |
| 3 | **두 방어선의 공을 잘못 돌림** — 게이트가 막은 걸 하드 게이트 공으로 | `demo.py` |
| 4 | `superseded_by` 컬럼만 있고 **로직이 없었다** — 술어 메타 2개 누락 | `fact_demo.py` |
| 5 | *"3회 세기"*인데 **무엇을 셀지를 안 정함** — `observation` 층 누락 | `interpret_demo.py` |
| **6** | **[docs/15](../docs/15-read-path-prompt.md)에서 설계한 `[알고 있는 것]` 블록이 구현에 없었다** — 회상 22% → 56% | `soak.py` |
| **7** | 그 수정이 **하드 게이트를 우회**했다 — 트랩이 평범한 턴에 주입 | `soak.py` |
| **8** | importance로는 못 거른다 — 술어에 **상시성(standing)** 필요 | `soak.py` |
| **9** | **θ=0.15가 정답을 깔고 앉아 있었다** — 격리 최적화 값이 시스템에선 최악 | `gate_sweep.py` |
| **10** | **게이트와 θ는 직렬이라 하나씩 바꾸면 둘 다 효과 0** — OFAT이 못 보는 상호작용 | `gate_sweep.py` |

### 🆕 [설계 요소 점검](../docs/16-design-elements.md)에서 추가된 것

목록을 훑어 찾은 것들이라 **실험으로는 안 나왔을** 기능이다.

| 기능 | 무엇을 고치나 |
|---|---|
| `add_event` **중복 제거** | 사건에 중복 방어가 없었다. 시점 버킷 + 어근 겹침 |
| `delete_item` **파생물 전파** | 사실을 지워도 요약에 남았다. `derivation`·`stale` |
| `_safe` **계층별 실패 정책** | 사실 계층 실패만 "조용한 환각"을 만든다 |
| `_migrate` **스키마 버전** | 필드만 있고 절차가 없었다 |

**3번이 특히 뼈아프다** — provenance의 첫 실제 효용이 *제 주장의 오류를 잡은 것*이었다.

**6~8번은 장난감 시드로는 안 나왔다.** 데모는 항목이 3~5개라 검색이 다 찾아냈고,
720턴을 넣고서야 파이프라인 전체의 도달률이 보였다. **규모가 결함을 드러낸다.**

> 그리고 소크 테스트가 실험 1~10의 해석을 바꿨다.
> 부품 벤치마크(`recall@5 = 70%`)와 시스템 실측(**22%**)의 격차가 48%p다.
> **부품 성능은 시스템 성능의 상한이지 예측치가 아니다.**

## 구현된 것 / 안 된 것

**구현됨**
- L0 원본 · L1 캐릭터(버전 고정) · L2 관계 · L3 씬 · L4 요약 2층 · L5 사실(bi-temporal) · L6 사건 · L9 부채(백오프) · M 커버리지 · provenance
- 읽기 경로 4단계 — 게이팅 → 하드 게이트 → 가중 정렬 → 임계 컷
- 컨텍스트 조립 (공유범위 × 내용변경 × 존재변경 순)
- 청크 축출 · surfaced_count 페널티 · 한국어 어미 정규화

**안 됨**
- **LLM이 없다.** 응답 생성·추출·요약이 전부 시드 데이터다. **조립만 검증한다**
- L8 해석 *생성* (누적 로직만 있고 관찰 추출은 LLM 필요)
- 동시성 · 트랜잭션 경계 · 마이그레이션 · 인증

**`_stem`은 nori의 대용품이지 대체재가 아니다.** 실서비스에서는 형태소 분석기를 써야 한다.
다만 **"없으면 좋은 것"이 아니라 "없으면 정답이 탈락하는 것"**임이 확인됐다.

## 파라미터

전부 [실험 7 스윕](../docs/11-experiment-results.md) 결과다. `memory.py` 상단에 모여 있다.

```python
TAU_IMPORTANCE   = 0.2   # 하드 게이트 (0.2~0.4 둔감구간)
THETA_RELEVANCE  = 0.15  # 임계 컷
WINDOW_TURNS     = 10    # 무릎
SURFACED_PENALTY = 0.1   # 무릎
WINDOW_CHUNK     = 10    # 청크 축출
MIN_EVIDENCE_FOR_INTERPRETATION = 3   # 수기 세션에서 도출
INJECT_KNOWN_FACTS = True             # 소크 발견 6 — 결정적 사실 주입
```

⚠️ **`THETA_RELEVANCE`는 0.15 → 0.05로 바뀌었고, `gate()`에 내용어 접점 판정이 추가됐다**
([실험 12](../docs/11-experiment-results.md)). **둘은 함께 바꿔야 효과가 난다** — 직렬이라
하나만 열면 다른 하나가 막는다. 파이프라인 전체 근거 도달률 **22% → 61%.**

`Memory.PREDICATE_STANDING`은 **결정적 주입 대상 술어 집합**이다(소크 발견 8).
여기 없는 술어(`일상_사소` 등)는 검색 경로로만 도달한다.
